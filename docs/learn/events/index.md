# Events

Conferences, summer schools and workshops where GLACIER is taught in person.

Each entry below is a **preparation page** for one session: what the session is,
what to install, what to download, and how to check that a laptop is ready.
That is all they are for. The reusable technical material stays where it
belongs — in [Tutorials](../tutorials.md) and the
[Frost documentation](../../frost/index.md).

## Adding one

Add one Markdown file under `docs/learn/events/`, then add it to the `Events`
section of `nav:` in `mkdocs.yml` and to the list above. Follow the structure of
[FDL 2026](fdl-2026.md): event metadata, one prominent download, the
prerequisites, the checks that prove the machine is ready, and a short
troubleshooting list. Keep it to logistics — link out for everything else.
